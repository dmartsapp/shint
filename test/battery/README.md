# The black-box battery

About 350 cases that run the **real `shint` binary** the way a user does and judge what comes out:
exit status, output, `--json` validity, timing, crashes. They complement the Go tests (which call the
code directly) by attacking from the outside: hostile HTTP servers, hosts and ports written every
odd way, flags at their limits, servers that reset or stall or lie, signals and closed pipes.

```
make test-battery                       # build the binary, run everything (about a minute)
make test-battery BATTERY_ARGS="--group F"      # only the web cases
make test-battery BATTERY_ARGS="--only trunc"   # cases whose id contains the text
make test-battery BATTERY_ARGS="--list"         # what there is
python3 test/battery/run.py --bin ./shint       # against a binary you already have (v4.0.5 works too)
```

`make test` (and so `make check`) runs it after the Go tests.

## How a case is judged

Every invocation must satisfy the invariants that hold for any command: no panic, exit status 0, 1
or 2, `--json` prints one valid JSON document, a usage error (2) goes to stderr and prints nothing
on stdout, exit 1 has an `ERROR` line saying why and exit 0 has none, nothing hangs. A case may add
its own expectations (`rc=`, `contains=`, `check=`).

## Known issues

A case that exposes a bug that is **still open** is listed in [`known_issues.py`](known_issues.py)
with its issue number. It must keep failing: the run stays green while the bug exists, and turns red
when the case starts to pass, telling you to delete the line - so fixing a bug and updating the list
happen in the same commit and the list cannot rot. Anything failing that is not listed fails the run.

## Adding a case

Add it to the `cases_*.py` module for its command (`add(id, args, rc=..., ...)`, or `add_func` for a
scripted case). `{http}`, `{tcp_echo}`, `{udp_closed}` and the other names in `servers.py` are
replaced by the port of the matching loopback server; `{good_pem}` and friends are throw-away TLS
files; `{version}` is `Version` from `main.go`. If the new case exposes a bug, open an issue and list
the case in `known_issues.py`.

## Needs

`python3` and `go` (a throw-away certificate is generated by `gencert`). IPv6 cases are skipped
without `::1`, TLS cases without the certificate, ping cases without unprivileged ICMP. Cases that
open hundreds of connections run one at a time, after the parallel ones. The suite never leaves the
machine.
